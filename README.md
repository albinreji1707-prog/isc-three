# India Social & Cultural Centre (ISC) Abu Dhabi - Portal Design

A premium, modern, and fully responsive web portal for the **India Social & Cultural Centre (ISC) Abu Dhabi**. Built with modern CSS design tokens, glassmorphism aesthetics, asymmetrical layouts, and interactive wizard modals.

## 🚀 Key Features

*   **Mockup-Exact Hero Layout**: An elegant desktop hero structure featuring a custom SVG clipping mask slant background and a synchronized 3-column compact responsive card system.
*   **Asymmetrical Bento Box Amenities Grid**: Replaces standard card grids with an alternating bento box structure (Sports, Dining, Auditorium, Leisure Hub) displaying full-height photography.
*   **Frosted Glass Slide-Reveal System**: Hover-reveal content drawers that translate upward smoothly on desktop viewports and display statically optimized on mobile screens.
*   **Multi-Step Facility Reservation Modal**: An interactive glass wizard modal with progress indicators that lets users book slots, customize date/times, and renders a virtual confirmed ticket with custom barcodes.
*   **Animated Back-to-Top Toggle**: A solid brand-red floating button that shows/hides dynamically on page scroll, with custom hover transitions and mobile scale adjustments.
*   **Zero-Jank Responsive Nav Drawer**: An off-canvas mobile drawer with smooth transforms, locked body scroll, and responsive alignment synchronization.

## 🛠️ Technology Stack

*   **HTML5**: Semantic markup structures.
*   **CSS3**: Custom CSS properties (variables), Flexbox, Grid, custom keyframe transitions, and backdrop filters.
*   **JavaScript (ES6+)**: Custom DOM event handlers, auto-scrolling mobile lists, intersection observers, and wizard step validations.
*   **Icons**: FontAwesome 6.4.0 integration.

## ⚙️ Running Locally

1. Clone this repository to your local machine:
   ```bash

   ```
2. Simply double-click `index.html` to open it in any modern browser, or run a local server (e.g., Live Server extension in VS Code) for the best local development experience.
